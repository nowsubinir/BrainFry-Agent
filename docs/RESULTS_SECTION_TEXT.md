# Results Section Text for Paper

주의: 아래 결과는 실제 인간 설문이 아니라 `run_evaluation.py`로 생성한 재현 가능한 자동 파일럿 평가입니다. 실제 설문을 진행하면 숫자를 교체하세요.

본 프로젝트에서는 20개의 소비자 구매 시나리오를 사용하여 Baseline LLM과 BrainFry Agent를 비교하였다. 평가에는 decision ease, satisfaction, confidence, cognitive load reduction, explanation quality, personalization, purchase intention의 7개 지표를 사용하였다. 자동 파일럿 평가 결과, BrainFry Agent는 모든 지표에서 Baseline LLM보다 높은 평균 점수를 보였다. 특히 cognitive load reduction과 personalization에서 차이가 크게 나타났으며, 이는 BrainFry Agent가 선택 피로를 명시적으로 탐지하고 소비자 유형에 맞춘 설명을 제공하기 때문으로 해석된다.
