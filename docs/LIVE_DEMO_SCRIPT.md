# 2–3 Minute Live Demo Script

이제 BrainFry Agent의 라이브 데모를 보여드리겠습니다. 예시 사용자는 무선 이어폰을 사고 싶지만 유튜브 리뷰를 2시간 넘게 보고 오히려 더 헷갈리는 상황입니다. 예산은 15만 원이고, 착용감과 통화 품질을 중요하게 생각합니다.

Run BrainFry Agent 버튼을 누르면 BrainFry Detector Agent가 긴 리뷰 시청 시간, 혼란 표현, 낮은 확신을 탐지합니다. 그 결과 BrainFry Level이 High로 분류됩니다.

다음으로 Psychology Agent는 사용자를 선택피로형 또는 후회 회피형에 가까운 유형으로 분류합니다. Product Search Agent는 상품 데이터베이스에서 예산과 우선순위에 맞는 상품을 필터링합니다. Decision Simplifier Agent는 정보 부담을 줄이기 위해 선택지를 2개 정도로 제한합니다.

마지막으로 Critic Agent가 예산, 우선순위, 추천 개수, 설명 품질을 점검합니다. 이 데모의 핵심은 일반 추천 챗봇처럼 많은 상품을 나열하는 것이 아니라, 사용자의 정보과부하 상태를 먼저 파악하고 선택지를 줄여 의사결정 부담을 낮춘다는 점입니다.
